# Assignment 1 本机环境

依赖：Apple Clang、CMake、Eigen、OpenCV，使用 C++17。
Eigen 和 OpenCV 由 CMake 自动查找，不需要手写 Homebrew 的头文件路径。

## VS Code

打开工作区 `/Users/mac/cyy/Games101`。

- `Cmd + Shift + B`：编译 Assignment1。
- 在“运行和调试”中选择 `Assignment1 (CMake)`，按 `F5`：编译并启动调试。
- Code Runner 的 C++ 运行按钮也已指向 Assignment1。
- Assignment0 的编译任务和调试配置仍可从列表中选择。

弹出图像窗口后，点击窗口使其获得焦点。`a` / `d` 调整旋转角度，`Esc` 退出。
`get_model_matrix()` 已实现绕 Z 轴旋转。

## 终端

```bash
cd /Users/mac/cyy/Games101
cmake -S "GAMES101-Homework/Assignment1/代码框架" -B build/Assignment1 -DCMAKE_BUILD_TYPE=Debug -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build build/Assignment1 --parallel
./build/Assignment1/Rasterizer
```

不打开窗口，直接生成图片：

```bash
./build/Assignment1/Rasterizer -r 0 /Users/mac/cyy/Games101/build/Assignment1/output.png
```

命令行模式可以省略输出文件名，此时在当前工作目录生成 `output.png`。
模型旋转、透视投影和任意过原点轴旋转均已实现，见 [README.md](README.md)。

在另一台已安装 Homebrew 的 Mac 上，可用 `brew install cmake eigen opencv` 安装依赖。
