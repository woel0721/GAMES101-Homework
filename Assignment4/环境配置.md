# Assignment4 本地环境

VS Code 请打开 `/Users/mac/cyy/Games101`，源码为 `GAMES101-Homework/Assignment4/code/main.cpp`。

依赖使用本机已有的 CMake、Apple Command Line Tools 和 OpenCV 5.0.0，编译标准为 C++17。CMake 优先使用独立 Command Line Tools，避免默认 Xcode 工具链的许可证问题。

## 运行与调试

本节的启动脚本和 VS Code 快捷配置位于本机仓库的上层工作区，不包含在此 Git 仓库中。其他机器克隆后可以使用下面的手动构建命令。

在工作区根目录的终端运行：

```sh
./run-a4.command
```

也可以双击该脚本，或在 VS Code 中使用右上角 Run Code。脚本会先配置、编译，再启动程序。

- `Cmd+Shift+B`：构建 A4。
- F5：选择 `Assignment4 (CMake)`，先构建再启动 LLDB 调试。
- 运行任务 `Run Assignment4`：先构建再启动窗口。

在 `Bezier Curve` 窗口里单击四个控制点，框架自带的 `naive_bezier` 绘制红色曲线，`bezier` 使用 de Casteljau 递归求点并绘制绿色距离加权反走样曲线，两者叠加显示。图片保存到运行目录的 `my_bezier_curve.png`。按任意键结束；选四点之前可按 Esc 退出。

## 手动构建

在 Git 仓库 `GAMES101-Homework` 根目录执行（需先安装 CMake 和 OpenCV）：

```sh
cmake -S Assignment4/code -B build/Assignment4 -DCMAKE_BUILD_TYPE=Debug
cmake --build build/Assignment4 --parallel 2
cd build/Assignment4
./BezierCurve
```

以上命令生成仓库内的 `build/Assignment4/compile_commands.json`。本机上层工作区的 VS Code 配置则使用上层工作区内的同名构建目录。若 VS Code 仍显示旧诊断，执行 `CMake: Configure`，必要时执行 `Developer: Reload Window`。
